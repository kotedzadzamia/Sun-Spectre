SECURITY

Responsible Disclosure

Sun Spectre welcomes good-faith reports of security issues affecting this website or systems we operate.

How to report

Email hello@sunspectre.com with the subject “Security Disclosure”. Include a clear description, affected URL or component, reproduction steps, impact and any supporting evidence that can be shared safely.

Good-faith research

Please avoid actions that disrupt services, access data that is not yours, degrade availability, perform social engineering, send spam, install malware or intentionally cause harm. Use the minimum testing necessary to demonstrate the issue.

Data handling

If you encounter sensitive information, stop testing, do not retain or distribute the information, and include enough detail in your report for us to investigate.

What to expect

We will aim to acknowledge a legitimate report and assess its severity as soon as reasonably practicable. Resolution timing depends on complexity, impact and dependencies.

Recognition

We appreciate responsible security research. Any public recognition or disclosure timing should be coordinated with Sun Spectre before publication.
