# Sun Spectre

Static marketing website for Sun Spectre — AI governance, cybersecurity, vCISO, IT audit, GRC and technology risk consulting.

## Main pages

- `index.html` — Homepage
- `products.html` — Productized engagements and Control View
- `services.html` — Comprehensive service catalogue
- `industries.html` — Industry expertise
- `insights.html` — Perspectives and resource center
- `about.html` — Who we are, principles and 7D method
- `talk-to-us.html` — Consultation request
- `contact.html` — Contact page
- `capabilities.html` — Capability overview
- `privacy.html`, `terms.html`, `responsible-disclosure.html` — Legal/security pages
- `404.html` — Branded not-found page

## Navigation

The reusable SentinelOne-inspired floating navigation and mega menus are generated by `script.js`. Shared responsive visual styles live in `styles.css`.

## Deployment

The repository is configured for Cloudflare static asset deployment with `wrangler.jsonc`. The static asset directory is the repository root so `index.html`, CSS, JavaScript, redirects, headers and supporting pages are deployed together.

Changes pushed to `main` should trigger the connected Cloudflare deployment when the GitHub integration is enabled.
